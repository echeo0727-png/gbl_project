spec.md 맨 아래에 '## 출시' 항목을 추가해 줘. 다른 부분은 건드리지 마.\
웹 배포는 GitHub Pages, 원스토어 Web 상품은 웹게임 SDK 기본 연동,\
일반 브라우저에서는 SDK 없이 지금처럼 플레이, 광고와 결제는 넣지 않음.
spec.md의 '출시' 항목대로 원스토어 웹게임 SDK를 기본 연동해 줘.\
SDK는 index.html의 최상위 스크립트에서 게임 코드와 [Phaser]보다 먼저 불러와 줘.\
일반 브라우저(GitHub Pages, Live Server)에서는 지금처럼 그대로 플레이되어야 해.\
initializeAsync 결과에 err가 있으면 원스토어 앱이 아닌 것으로 보고 게임을 바로 시작해 줘.\
로딩 진행률을 setLoadingProgress로 알려 주고, 로딩이 끝나면 startGameAsync를 호출해 줘.\
pause 때는 게임과 소리를 멈추고 resume 때 다시 시작해 줘.\
광고와 결제는 넣지 마. 고치기 전에 무엇을 바꿀지 먼저 보여 줘.
AGENTS.md, spec.md, design.md를 읽고 프로젝트 폴더에 index.html을 만들어 줘.\
\
이번에는 실행 확인용 첫 화면까지만 만들어 줘.\
\- Phaser 3는 CDN으로 불러오고, 게임 코드는 main.js로 분리해 줘.\
\- 화면은 모바일 세로 기준으로 만들고, 도형과 글자만 사용해 줘.\
\- 제목 ‘100만 원으로 세계여행하기’, 시작 예산 ‘1,000,000원’, ‘게임 시작’ 버튼을 표시해 줘.\
\- 시작 버튼을 클릭하거나 터치하면 ‘여행을 시작합니다’가 표시되게 해 줘.\
\- 문서에서 [미정]인 내용은 임의로 확정하지 말아 줘.
